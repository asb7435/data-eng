압축 방식 비교: zstd 9.8 MB / snappy 15.9 MB / gzip 10.6 MB

거꾸로 나온 측정: count(*) 로 잰 「전부 읽기」가 더 빨랐던 이유 — Parquet의 메타데이터에 저장된 행 수를 이용하면 실제 데이터를 모두 읽지 않고도 개수를 계산할 수 있기 때문이다. 따라서 count(*)의 0.0010초는 다섯 열을 실제로 모두 읽는 시간이 아니다.

결론: 중간 산출물을 Parquet로 저장
